# 术语表（共享码本）

| 术语 | 含义 |
|---|---|
| 工艺窗口 | 某个材料、螺钉、几何组合下允许的终止扭矩范围、目标值和分段策略 |
| 业务流 | 设备无关的工站动作序列描述（station/flow.yaml），agent 主要写这一层 |
| 交接 tier0 | 机械臂与执行器之间的四根信号：就绪、接管、完成、异常 |
| 治具坐标系 | 所有紧固点坐标的参考系。现场只标定它，不逐点示教 |
| 设计孪生 | agent 组合出来的工站方案在仿真中的版本 |
| 现场孪生 | 设计孪生加上现场自标定和实测数据 |
| 擦除 | 信息缺失或超出范围时明确返回"未知"，而不是补一个看起来合理的值 |
| 签字关口 | 必须由人确认才能继续的节点：可制造性、工艺窗口、工站方案、首件放行 |
